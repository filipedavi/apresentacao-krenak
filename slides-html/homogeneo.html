“Uma humanidade com o mesmo protocolo”

3 min. A homogeneização não é só econômica, é informacional. Krenak: a narrativa globalizante oferece o mesmo cardápio, o mesmo figurino e, se possível, a mesma língua para todo mundo (p. 12). Formamos consumidores, não cidadãos (Mujica). A cada ano uma língua materna é deletada; ficam as que interessam às corporações; no Brasil ainda resistem mais de 150. A humanidade com o mesmo protocolo (p. 16) até agora só serviu para homogeneizar e tirar nossa alegria de estar vivos. Guardar as palavras deletar e protocolo: voltam no fim.
