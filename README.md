# Ideias para adiar o fim do mundo — apresentação

Seminário sobre *Ideias para adiar o fim do mundo* (Ailton Krenak, 2019) para a disciplina
Cultura e Informação (ECI/UFMG), 19/11/2026.

- `index.html` — a apresentação. Abra no navegador (ou pelo GitHub Pages). Setas navegam, `N` mostra as notas, `F` tela cheia.
- `slides-html/` — um arquivo por slide, na ordem de `slides-html/deck.json`. É aqui que se edita.
- `roteiro-falas.md` — o roteiro de fala, slide a slide.
- `imagens/`, `fonts/` — recursos locais; a apresentação funciona sem internet.

Para regenerar `index.html` depois de editar um slide, veja o passo a passo no fim deste arquivo.
